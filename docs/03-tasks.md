# 03. Задачи для Claude Code

Формат: короткие независимые задачи с критерием готовности. Брать по порядку. Перед стартом прочитать `CLAUDE.md`, `01-brief.md`, `02-physics.md`.

Статусы: `[ ]` не начато, `[~]` в работе, `[x]` готово.

## Этап 0. Подготовка

- [ ] **T0.1** Принять решения из `04-decisions.md` пп. 1–3 (версия Minecraft и Fabric, одиночная игра или мультиплеер, масштаб).
  *Готово, когда*: решения записаны в `04-decisions.md`.
- [ ] **T0.2** Создать проект `tf2-mc` из шаблона Fabric выбранной версии.
  *Готово, когда*: пустой мод собирается и запускается (`./gradlew runClient`).

## Этап 1. Движение

- [ ] **T1.1** Создать чистый класс `SourceMovement` (без зависимостей от Minecraft) с параметрами из `02-physics.md`: трение, ускорение на земле, ускорение в воздухе с ограничением `wishspeed`.
  *Готово, когда*: юнит-тесты из раздела 7 `02-physics.md` проходят.
- [ ] **T1.2** Конфиг параметров (`sv_accelerate`, `sv_airaccelerate`, `sv_friction`, масштаб, подшаги). Читать при старте, возможность перечитать командой.
  *Готово, когда*: смена значения в конфиге меняет поведение без пересборки.
- [ ] **T1.3** Mixin в движение игрока: вызывает `SourceMovement`, выполняется на клиенте и на сервере одинаково.
  *Готово, когда*: на плоском мире игрок разгоняется и стрейфит в воздухе; в связке «выделенный сервер + клиент» нет сообщений «moved wrongly».
- [ ] **T1.4** Подшаги (вариант A из `02-physics.md`) и сравнение с одним шагом.
  *Готово, когда*: выбран вариант, решение записано.

## Этап 2. Каркас классов

- [ ] **T2.1** Хранение класса игрока и команда `/tf2 class <имя>`.
- [ ] **T2.2** Применение HP и максимальной скорости класса при смене; сброс экипировки.
- [ ] **T2.3** Данные классов в `data/classes.json` (таблица из `01-brief.md`, после проверки по вики).

## Этап 3. Первые классы

- [ ] **T3.1 Soldier: ракета.** Сущность-снаряд со скоростью по вики, проверка столкновений вдоль пути за тик, кастомный взрыв без разрушения блоков.
- [ ] **T3.2 Soldier: отбрасывание и самоурон.** Формулы с вики, отправка скорости клиенту.
  *Готово, когда*: ракетный прыжок на плоской карте даёт высоту и дальность, сопоставимые с TF2.
- [ ] **T3.3 Soldier: оружие.** Боезапас, перезарядка, интервал выстрела по вики.
- [ ] **T3.4 Scout: двойной прыжок** и скорость 133%.
  *Готово, когда*: распрыжка Scout воспроизводима и ощущается близкой к TF2.
- [ ] **T3.5–T3.9** Pyro, Heavy, Medic, Demoman, Sniper (по одной задаче на класс, разбить подробнее после T3.4).
- [ ] **T3.10–T3.11** Engineer и Spy (каждая разбивается на несколько задач отдельно).
