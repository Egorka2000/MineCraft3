# tf2-mc — рабочая папка проекта

Перенос классов Team Fortress 2 (стоковое оружие) в Minecraft на Fabric.

## Структура

```
tf2-mc/
├── CLAUDE.md              # короткий контекст для Claude Code (читается автоматически)
├── README.md              # описание проекта для GitHub
├── LICENSE                # Apache License 2.0
├── docs/                  # проектные документы (эта папка)
│   ├── README.md          # индекс и правила работы с документами
│   ├── 01-brief.md        # бриф: цели, scope, данные классов, этапы
│   ├── 02-physics.md      # спецификация физики: тикрейт, масштаб, формулы
│   ├── 03-tasks.md        # задачи для Claude Code (этапы 1–3)
│   ├── 04-decisions.md    # открытые вопросы и журнал решений
│   ├── 05-sources.md      # числа TF2: значение, страница вики, дата сверки
│   ├── 06-references.md   # похожие моды и документация
│   ├── 07-plan.md         # план действий до первой вехи
│   └── 08-architecture.md # архитектура: модули, границы, сеть, тесты
├── .github/workflows/     # CI: сборка и тесты на каждый PR и коммит в main
├── .editorconfig          # отступы и кодировка для редактора
├── config/checkstyle/     # правила линтера Checkstyle
├── build.gradle           # сборка (Gradle приходит через gradlew, отдельно не ставится)
├── gradle.properties      # версии Minecraft, Fabric и зависимостей
├── physics/               # подпроект на чистой Java: математика движения, свои юнит-тесты
├── src/
│   ├── main/              # общий код мода и его данные
│   ├── client/            # код только для клиента
│   ├── test/              # юнит-тесты (JUnit)
│   └── gametest/          # серверные игровые тесты
└── tmp/                   # рабочие и временные файлы, в git не попадает
```

Папки `build/`, `run/` и `.gradle/` создаёт сборка, в git они не попадают.

## Правила

- Документы пишутся в Markdown, по одному файлу на тему.
- Числа из TF2 Wiki помечаются **[проверить]**, пока не сверены со страницей вики. Не брать цифры «из головы».
- Сверенное число записывается в `05-sources.md` со ссылкой на страницу и датой. Только после этого оно попадает в код или в файлы данных мода (`src/main/resources/data/tf2mc/`).
- Любое принятое решение записывается в `04-decisions.md` с датой.
- После каждой крупной волны изменений документы обновляются: статус задач в `03-tasks.md`, состояние в `07-plan.md`.
- Рабочие и временные файлы кладутся только в `tmp/`, после использования удаляются.
- Начало сессии с Claude Code: «Прочитай CLAUDE.md и docs/README.md, затем возьми следующую задачу из docs/03-tasks.md».
- Ассеты Valve (модели, звуки, текстуры) не используются. Цифры с вики использовать можно.
- Код Source SDK не копируется: алгоритм переписывается своими словами.
