# tf2-mc — рабочая папка проекта

Перенос классов Team Fortress 2 (стоковое оружие) в Minecraft на Fabric.

## Структура

```
tf2-mc/
├── CLAUDE.md              # короткий контекст для Claude Code (читается автоматически)
├── docs/                  # проектные документы (эта папка)
│   ├── README.md          # индекс и правила работы с документами
│   ├── 01-brief.md        # бриф: цели, scope, данные классов, этапы
│   ├── 02-physics.md      # спецификация физики: тикрейт, масштаб, формулы
│   ├── 03-tasks.md        # задачи для Claude Code (этапы 1–3)
│   └── 04-decisions.md    # открытые вопросы и журнал решений
├── src/                   # код мода (появится после инициализации Fabric-проекта)
└── data/                  # JSON-таблицы: классы, оружие (этап 4)
```

## Правила

- Документы пишутся в Markdown, по одному файлу на тему.
- Числа из TF2 Wiki помечаются **[проверить]**, пока не сверены со страницей вики. Не брать цифры «из головы».
- Любое принятое решение записывается в `04-decisions.md` с датой.
- Начало сессии с Claude Code: «Прочитай CLAUDE.md и docs/README.md, затем возьми следующую задачу из docs/03-tasks.md».
- Ассеты Valve (модели, звуки, текстуры) не используются. Цифры с вики использовать можно.
- Код Source SDK не копируется: алгоритм переписывается своими словами.
