# 09. Команды мода

Все команды начинаются с `/tf2`. Документ описывает состояние после шага 10; при добавлении или изменении команды он обновляется в том же PR.

## Общие правила

- **Ник в конце.** У команд, действующих на игрока, последний аргумент — необязательный ник. Без ника команда применяется к тому, кто её ввёл; с ником — к названному игроку.
- **Права.** «Оператор» — игрок с уровнем прав 2 и выше (в одиночной игре — мир с включёнными читами) или консоль сервера. Указывать чужой ник может только оператор.
- **Консоль сервера.** У консоли нет своего игрока, поэтому ник для неё обязателен.
- **Что сохраняется.** Класс игрока сохраняется между перезапусками. Здоровье и оверхил сохраняет сама игра. Спидометр живёт только до перезахода.

## Класс

### `/tf2 class`

Пишет в чат имя вашего класса или `vanilla`, если класса нет.

### `/tf2 class soldier [ник]`

Выдаёт класс. Свой класс выбирает любой игрок; чужой, с ником, назначает оператор. Сразу после команды:

- максимум здоровья становится 200, здоровье восполняется до максимума, оверхил сбрасывается;
- включается движение TF2 со скоростью 240 u/s;
- начинают действовать правила здоровья класса (см. `10-mechanics.md`).

Сейчас класс один. Остальные появятся после первой вехи, и для каждого будет такая же команда.

### `/tf2 class vanilla [ник]`

Снимает класс: движение, здоровье, сытость и урон от падения снова ванильные. Максимум здоровья возвращается к 20, лишнее здоровье и оверхил срезаются.

## Здоровье

Отладочные команды. Работают и для игрока без класса, но оверхила у него нет: здоровье не поднимется выше его максимума.

### `/tf2 health set <число> [ник]`

Выставляет здоровье вместе с оверхилом. Число — целое, не меньше 1.

- До максимума класса включительно: выставляется здоровье, оверхил убирается.
- Выше максимума: здоровье полное, остаток становится оверхилом. Правило 150% на команду не действует: предел только тот, что может хранить игра, — 2048 единиц оверхила.

Примеры для Soldier: `set 50` — 50 HP; `set 250` — 200 HP и 50 оверхила; `set 999` — 200 HP и 799 оверхила.

Оверхил, выставленный командой, спадает с той же скоростью, что и обычный: у Soldier по 6,67 в секунду.

### `/tf2 health add <число> [ник]`

Прибавляет число к текущему здоровью с оверхилом. Отрицательное число отнимает; ниже 1 здоровье этой командой не опустится, убить ею нельзя.

Команда отвечает итоговым значением здоровья.

## Команды игроков

Игроки одной команды не наносят друг другу урон; ники окрашены в цвет команды. Команда сохраняется между перезапусками.

Игрок, который вошёл в мир и ещё не выбрал команду, попадает в нейтральную: серый ник, в бою не участвует — не ранит других игроков и не получает урон от них. Выбрать нейтральную команду нельзя, в неё попадают только при входе в мир.

### `/tf2 team`

Пишет в чат вашу команду и списки игроков, которые сейчас на сервере: красные, синие, нейтральные. С консоли сервера показывает только списки.

```
tf2-mc: ваша команда — red
red (2): Egor, Alex
blu (1): Max
нейтральные (0)
```

### `/tf2 team red|blu [ник]`

Зачисляет в красную или синюю команду. Свою команду выбирает любой игрок, чужую назначает оператор.

### `/tf2 team random [ник]`

Зачисляет в команду, где сейчас меньше игроков на сервере; при равенстве — в случайную.

### `/tf2 team spectator [ник]`

Выводит из команды и переводит в ванильный режим наблюдателя. При следующем выборе команды возвращается режим игры, который был до наблюдения.

Команда и класс не связаны: команду можно выбрать и без класса.

## Ракета

### `/tf2 rocket [ник]`

Выпускает ракету из глаз игрока по направлению его взгляда. Отладочная команда для операторов; у игрока должен быть выбран класс.

В игре ракета выпускается без команды: правая кнопка мыши с ракетницей в руке. Ракетница выдаётся вместе с классом. Команда `/tf2 rocket` работает в обход ракетницы и боезапас не тратит.

## Боезапас

Отладочные команды для операторов. Работают, только если у игрока есть ракетница, то есть выбран класс.

### `/tf2 ammo refill [ник]`

Полная обойма и полный запас: 4 / 20.

### `/tf2 ammo set <число> [ник]`

Выставляет запас ракет, от 0 до 20. Обойму не меняет.

### `/tf2 ammo add <число> [ник]`

Прибавляет к запасу; отрицательное число отнимает. Запас не выходит за границы от 0 до 20.

## Спидометр

### `/tf2 speed [on|off] [ник]`

Без слова `on` или `off` команда переключает спидометр у того, кто её ввёл: включён — выключит, выключен — включит.

Над панелью быстрого доступа показывается строка с двумя числами:

- горизонтальная скорость в u/s, по фактическому смещению за тик;
- высота последнего прыжка в u.

Нужен для замеров и сравнения с TF2. Работает и без класса, тогда показывает ванильное движение в тех же единицах.

## Настройки

### `/tf2 config`

Показывает действующие значения: параметры движения, масштаб `unitsPerBlock`, число подшагов. На сервере это значения сервера: клиенты считают движение по ним.

### `/tf2 reload`

Перечитывает `config/tf2mc.json` без перезапуска и рассылает новые значения всем игрокам.

- Ошибка в файле настройки не сбрасывает: остаются прежние значения, причина пишется в чат и в лог.
- О неизвестном параметре приходит предупреждение: обычно это опечатка.

Описание файла — в `08-architecture.md`, раздел 7.

## Как проверить мод за минуту

1. `/tf2 class soldier` — на экране `HP 200`, движение стало резким, без разгона «по льду».
2. `/tf2 speed on` — на ровной земле скорость около 240 u/s, прыжок около 52 u.
3. `/tf2 health set 300` — число голубое и убывает до 200 за 15 секунд. `/tf2 health set 1000` — оверхил выше 150%, так можно только командой.
4. Спрыгнуть с высоты 7–8 блоков — здоровье уменьшится; с 5 блоков урона нет.
5. `/tf2 team` — вы в нейтральной команде. `/tf2 team red` — ник становится красным; второй игрок той же команды не может вас ранить.
6. Возьмите ракетницу — она уже в инвентаре, — посмотрите под ноги, прыгните и нажмите правую кнопку мыши: ракетный прыжок. Внизу справа боезапас «3 / 20».
7. `/tf2 class vanilla` — всё возвращается к обычной игре.
