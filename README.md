# tf2-mc

Fabric-мод для Minecraft Java Edition: классы Team Fortress 2 со стоковым оружием. Главный приоритет — движение в стиле Source: ракетный прыжок и распрыжка.

Проект в самом начале: есть движение в стиле Source с правилами TF2 (разгон, трение, стрейф в воздухе, прыжок, потолок скорости класса) и первый класс — Soldier: 200 HP и скорость 240 u/s. Движение TF2 включается выбором класса. При выбранном классе здоровье живёт по правилам TF2: урон от падения, оверхил, без сытости и регенерации. Оружия ещё нет; следующий шаг — ракета и ракетный прыжок.

## Сборка и запуск

Нужен JDK 25. Gradle ставить не надо, он скачивается сам при первом запуске. На Windows команды запускаются как `gradlew.bat`, на Linux и macOS как `./gradlew`.

| Команда | Что делает |
|---|---|
| `gradlew build` | Собирает мод, запускает линтеры и все тесты, jar с версией в имени появляется в `build/libs/` |
| `gradlew check` | Только линтеры и тесты, без сборки jar |
| `gradlew test` | Только юнит-тесты |
| `gradlew :physics:test` | Только тесты математики движения, без загрузки игры |
| `gradlew runGameTest` | Только серверные игровые тесты |
| `gradlew runClientGameTest` | Клиентские игровые тесты: открывается окно игры, тест сам нажимает клавиши и измеряет движение |
| `gradlew runClient` | Запускает игру с модом |
| `gradlew runServer` | Запускает выделенный сервер с модом |

Minecraft 26.3, Fabric Loader 0.19.5, Fabric API 0.162.0+26.3.

## Настройки и команды

Файл настроек `config/tf2mc.json` создаётся при первом запуске (в разработке — `run/config/tf2mc.json`). В нём параметры движения в единицах TF2, масштаб и число подшагов; описание — в [docs/08-architecture.md](docs/08-architecture.md), раздел 7.

| Команда | Что делает |
|---|---|
| `/tf2 config` | Показывает действующие настройки |
| `/tf2 reload` | Перечитывает файл настроек без перезапуска, только для операторов |
| `/tf2 class` | Показывает ваш класс |
| `/tf2 class soldier [ник]` | Выдаёт класс Soldier: 200 HP, скорость 240 u/s, движение в стиле Source; только для операторов |
| `/tf2 class vanilla [ник]` | Снимает класс и возвращает обычного игрока; только для операторов |
| `/tf2 health set <число> [ник]` | Выставляет здоровье; всё выше максимума класса становится оверхилом. Только для операторов |
| `/tf2 health add <число> [ник]` | Прибавляет здоровье, отрицательное число отнимает. Только для операторов |
| `/tf2 team red\|blu\|spectator\|random [ник]` | Команда игрока: свои друг друга не ранят. `random` — где меньше игроков, `spectator` — наблюдатель. `/tf2 team` показывает свою команду |
| `/tf2 speed [on|off] [ник]` | Спидометр: скорость в u/s и высота последнего прыжка; без слова — переключает ||off [ник]` | Спидометр: скорость в u/s и высота последнего прыжка |

Ник в конце необязателен. Без него команда применяется к тому, кто её ввёл; с ником — к названному игроку, и для этого нужны права оператора.

Подробно о командах — [docs/09-commands.md](docs/09-commands.md), о механиках мода — [docs/10-mechanics.md](docs/10-mechanics.md).

- Ассеты Valve (модели, звуки, текстуры) не используются.
