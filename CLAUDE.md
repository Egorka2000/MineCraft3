# tf2-mc

Fabric-мод: классы Team Fortress 2 со стоковым оружием в Minecraft Java Edition. Приоритет номер один: движение в стиле Source (ракетный прыжок, распрыжка).

## Документы

Читать в начале сессии: `docs/README.md`, затем по необходимости `docs/01-brief.md`, `docs/02-physics.md`, `docs/03-tasks.md`, `docs/04-decisions.md`, `docs/05-sources.md`, `docs/06-references.md`, `docs/07-plan.md`, `docs/08-architecture.md`.

## Правила работы

- Брать следующую невыполненную задачу из `docs/03-tasks.md`, после выполнения отмечать `[x]`.
- Принятые решения записывать в `docs/04-decisions.md`.
- Числа TF2 с пометкой **[проверить]** сверять с TF2 Wiki, не угадывать. Результат сверки записывать в `docs/05-sources.md`.
- Математика движения живёт в чистом Java-классе без зависимостей от Minecraft, Mixin только вызывает его. Один и тот же код на клиенте и сервере.
- Не копировать код Source SDK и ассеты Valve. Алгоритмы переписывать своими словами.
- Одна задача — одна ветка и один PR в `main`. После слияния PR сразу убирать хвосты: удалить рабочую ветку локально и на GitHub, перевести локальный `main` на `origin/main`. Смерженные ветки не копить.
- После каждой крупной волны изменений, не дожидаясь напоминания:
  - закоммитить работу в ветку задачи;
  - обновить документы: статус в `docs/03-tasks.md` и `docs/07-plan.md`, решения в `docs/04-decisions.md`, затронутые разделы остальных документов. Документация должна описывать текущее состояние проекта;
  - убрать за собой: временные файлы, логи, остановленные тестовые процессы игры.
- Не захламлять проект. Рабочие и временные файлы создавать только в `tmp/` в корне (папка в `.gitignore`) или в системной временной папке, после использования удалять. Новые папки в корне не заводить без необходимости; если папка нужна, описать её в `docs/README.md`.
- Перед PR прогонять `gradlew build`: он включает юнит-тесты и игровые тесты. PR вливается только с зелёным CI.
- Перед изменением версии Minecraft, Fabric или зависимостей спрашивать меня.
- Язык общения и документации: русский.
